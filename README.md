# MyCinema TV

Protótipo de launcher/catálogo pessoal para Android TV e NVIDIA Shield.

## O que já funciona
- Interface adaptável para TV e navegador.
- Navegação por controle/teclado usando as setas.
- Perfil adulto e área infantil com listas separadas.
- Inclusão manual de filmes e séries.
- Listas persistidas no navegador com localStorage.
- Pesquisa de trailer no YouTube.

## Testar
Abra `index.html` em um navegador moderno. Não há dependências, instalação, build ou backend.

## Limitações atuais
- Os títulos de exemplo são demonstrativos.
- As listas ficam no armazenamento local do navegador; não sincronizam entre aparelhos.
- Os botões UniTV/Stremio ainda não iniciam reprodução.
- Não há integração com Trakt, TMDB ou serviços de streaming nesta versão.
