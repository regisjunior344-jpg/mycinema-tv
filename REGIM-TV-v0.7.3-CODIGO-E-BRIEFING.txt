1. OBJETIVO FINAL

REGIM TV é um launcher/interface pessoal para Android TV, desenvolvido principalmente para a NVIDIA Shield. A intenção é que ele seja a tela inicial principal da Shield, substituindo a experiência padrão do launcher Android TV, inclusive quando o usuário pressiona o botão Home do controle remoto. O resultado desejado é uma interface de TV elegante, rápida, cinematográfica, simples de navegar pelo controle remoto e que reúna aplicativos, filmes, séries e áreas separadas por perfil.

Não é para parecer um painel genérico cheio de widgets. A prioridade é uma interface limpa, visualmente refinada, com foco no conteúdo e nos aplicativos. Evitar anúncios e elementos grandes/desnecessários.

IMPORTANTE PARA QUEM FOR CONTINUAR:
- Esta pasta representa o código-fonte atual da versão 0.7.3, não uma promessa de que tudo já esteja perfeito.
- A versão 0.7.3 foi compilada com sucesso, mas as alterações visuais e de navegação precisam ser validadas na NVIDIA Shield real.
- Não remover funcionalidades existentes nem redesenhar partes aprovadas sem necessidade.
- Fazer alterações incrementais, preservando o que já funciona.
- Antes de gerar uma nova versão, revisar o JavaScript para erros de sintaxe e testar a navegação por setas/OK/Back.
- O APK Android carrega a interface web hospedada no GitHub Pages: https://regisjunior344-jpg.github.io/mycinema-tv/
  Portanto, mudanças em index.html precisam também estar publicadas no Pages. O APK e a página hospedada são partes do mesmo produto.

2. PLATAFORMA E ARQUITETURA

- Dispositivo-alvo: NVIDIA Shield Android TV.
- Aplicativo Android: pacote com.regimtv.launcher.
- Wrapper Android em Kotlin: app/src/main/java/com/regimtv/launcher/MainActivity.kt.
- Interface principal: index.html, com HTML, CSS e JavaScript.
- O wrapper Android disponibiliza uma ponte JavaScript nativa para listar e abrir aplicativos instalados, abrir Play Store e abrir configurações.
- Build: Android Gradle Plugin 8.7.3, Kotlin Android, Gradle 8.9 e JDK 17.
- O projeto deve continuar compatível com navegação por controle remoto (D-pad), não apenas mouse/touch.
- Versão atual: 0.7.3, versionCode 10.

3. DIREÇÃO VISUAL / HOME

A interface desejada é cinematográfica, limpa e minimalista:
- Fundo escuro, com cores e artwork dos conteúdos criando o ambiente visual.
- Sidebar vertical fina à esquerda, com ícones e rótulos curtos.
- Marca REGIM TV discreta no topo esquerdo.
- Relógio, data e clima discretos; exemplo que o usuário deu: Swindon e temperatura pequena, sem widget grande.
- Evitar widgets grandes e cabeçalhos que ocupem muito espaço.
- A área principal deve privilegiar os aplicativos, capas, listas e conteúdo.
- O painel/cabeçalho fixo deve ser compacto; a intenção é que somente as listas/área de conteúdo rolem quando necessário.
- O usuário já mostrou uma referência visual e aprovou uma direção geral; preservar o estilo aprovado em vez de propor um redesign completo.

4. SIDEBAR E NAVEGAÇÃO PRINCIPAL

A navegação lateral deve ser simples, com ícones e texto em caixa alta. As áreas e rótulos existentes no código incluem:
- APPS
- MOVIES & TV
- KIDS AREA
- SEARCH TITLE
- PLAY STORE
- SETTINGS

Em conversas anteriores, o usuário também descreveu a ideia de My Area / Kids, Play Store e Settings. O código atual usa os rótulos acima; não renomear sem confirmar.

Comportamento esperado:
- D-pad para cima/baixo percorre a sidebar.
- Direita entra na área principal apropriada.
- Esquerda retorna para a sidebar quando o foco está no primeiro item de uma lista/grade.
- O botão Back/Escape deve retornar à área/menu correto, não mandar sempre para Settings.
- A navegação precisa manter foco visível e previsível.
- A tela deve acompanhar o foco quando o usuário percorre listas longas, rolando verticalmente a área de conteúdo para que a fileira atual não fique escondida.

5. APPS HOME / GRADE DE APLICATIVOS

A área APPS é uma das telas centrais. Ela deve mostrar os aplicativos Android instalados na Shield, com ícones nativos reais quando disponíveis, e permitir abrir os apps diretamente.

Requisitos de aparência:
- Grade com quatro colunas por três linhas em telas de TV, quando o espaço permitir.
- Cards dos apps retangulares (não quadrados), bem proporcionados e consistentes.
- Ícone do app dentro do card, sem um segundo retângulo/cartão desnecessário envolvendo o ícone.
- Nome do aplicativo centralizado abaixo do ícone/card, sem ser cortado nem sobreposto ao ícone.
- O outline/foco deve acompanhar exatamente o formato e as bordas do card; não pode ficar retangular de tamanho diferente do próprio card.
- Foco elegante, com contorno/glow discreto e pequena ampliação, sem distorcer o layout.
- Espaçamento consistente entre cards, nomes e botão CUSTOM.
- O botão CUSTOM deve ficar afastado do último app da grade e preferencialmente centralizado na região inferior, sem parecer grudado ao último card.

6. CUSTOM / MANAGE APPS

Existe uma opção CUSTOM na tela APPS para abrir a janela de gerenciamento de aplicativos.

Objetivos:
- Gerenciar quais aplicativos aparecem na grade principal.
- Adicionar/remover aplicativos dos favoritos da Home.
- Reordenar favoritos para escolher a ordem da grade.
- O gerenciamento deve refletir a mesma ordem da tela APPS.
- A janela deve ser visualmente transparente/translúcida o suficiente para continuar vendo a grade por trás enquanto o usuário organiza os aplicativos.
- Não usar um fundo opaco que esconda completamente a grade.
- A navegação com controle remoto precisa funcionar em todas as direções.
- Em particular, setas para cima e para baixo devem mover o foco entre as linhas/opções de aplicativos, não ficar presas ou navegar de forma imprevisível.
- Setas esquerda/direita devem percorrer os controles da linha de forma lógica (favorito, mover para cima, mover para baixo), respeitando controles desabilitados.
- O botão de fechar deve ser alcançável.
- Enter/OK ativa o controle focado.

7. MOVIES & TV / CATÁLOGO

A área MOVIES & TV deve reunir filmes e séries com artwork/posters, detalhes e listas de conteúdo.
O projeto já possui integração com TMDB para carregar informações e imagens. A chave TMDB precisa ser configurada para que o catálogo ao vivo e os posters funcionem.
A tela deve manter o cabeçalho/hero compacto e deixar espaço para as fileiras de conteúdo.
Quando o usuário seleciona um título, a área de destaque deve apresentar as informações e artwork correspondentes.

A intenção é uma experiência de catálogo/launcher pessoal, não um serviço de streaming próprio. A interface organiza e apresenta títulos e direciona para os aplicativos disponíveis.

8. KIDS AREA

A Kids Area deve ser um perfil/área infantil separado da área adulta.
O usuário pediu que as fileiras/listas infantis fossem mantidas e restauradas, incluindo:
- Kids watchlist.
- Featured.
- Popular.
- A fileira que no código aparece como kidsTrendingSection / kidsTrendingRail (o nome técnico atual é esse; visualmente é a área Popular/Featured conforme a implementação).

Comportamento desejado:
- As fileiras Featured e Popular precisam ficar visíveis, não escondidas atrás de outras áreas.
- A navegação para baixo saindo da watchlist deve chegar à fileira seguinte.
- Quando o foco desce para a próxima fileira, a interface inteira precisa rolar para cima o suficiente para que a nova fileira fique visível.
- Não basta o foco mudar internamente: a tela precisa acompanhar o usuário.
- O movimento horizontal dentro de cada fileira deve rolar a fileira lateralmente quando necessário.
- A separação entre Kids e Movies & TV adulto deve ser preservada.

9. WATCHLISTS E FILEIRAS

O projeto tem watchlists e fileiras de catálogo. O controle remoto deve navegar pelas fileiras de maneira consistente:
- Esquerda/direita percorre os títulos na fileira.
- Ao chegar ao limite da fileira, não deve haver salto inesperado.
- Cima/baixo muda para a fileira anterior/seguinte quando existir.
- A rolagem vertical do container deve revelar a fileira focada.
- A rolagem horizontal da fileira deve revelar o card focado.
- O foco selecionado precisa ser claramente visível.

10. SEARCH TITLE

SEARCH TITLE deve permitir procurar filmes e séries no catálogo TMDB, apresentar resultados e permitir selecionar um resultado para ver detalhes e adicioná-lo à watchlist apropriada, conforme a lógica já existente.
O controle remoto precisa permitir entrar no campo de busca, navegar pelos resultados e voltar ao menu.

11. PLAY STORE E SETTINGS

- PLAY STORE deve abrir a Google Play Store nativa no Android TV por meio da ponte Android.
- SETTINGS deve permitir acesso às configurações relevantes do launcher e aplicativos/ajustes do Android TV, conforme a implementação existente.
- Os ícones e opções devem seguir o visual discreto da sidebar, sem criar grandes painéis/widgets.
- Preservar as funções nativas já existentes no wrapper.

12. OBJETIVO DE PLAYBACK / INTEGRAÇÃO COM UNITV — IDEIA FUTURA AINDA NÃO IMPLEMENTADA

O usuário já explicou uma ideia importante para o botão de ação do título (o botão atualmente identificado no código como "where"):
- Ao escolher um filme ou série no catálogo, o objetivo ideal é abrir o aplicativo UniTV diretamente na página daquele título, se for tecnicamente possível.
- Se não for possível fazer deep link para o título exato, a alternativa mínima desejada é abrir o UniTV diretamente na seção de filmes ou na área apropriada, em vez de simplesmente abrir a tela inicial genérica.
- O usuário quer que a experiência seja direta, sem precisar procurar o título manualmente dentro do app.
- Isto é uma ideia/objetivo futuro, não afirmar que já funciona. O código atual ainda contém uma mensagem placeholder para playback/integração.

13. PONTOS CONHECIDOS / BUGS A VALIDAR NA 0.7.3

A versão 0.7.1 teve um erro de sintaxe JavaScript causado por uma sequência literal de quebra de linha inserida no código, que interrompia o carregamento de todo o JavaScript e quebrava a navegação.
A correção foi feita na 0.7.2.

Na 0.7.3 foram feitas alterações para:
- Recuperar cards retangulares na grade APPS.
- Fazer o outline/foco acompanhar o card.
- Separar os nomes dos apps dos ícones e evitar cortes.
- Dar mais espaço e centralizar o botão CUSTOM.
- Aumentar a transparência da janela Manage Apps.
- Corrigir navegação vertical no Manage Apps.
- Melhorar a rolagem da área de conteúdo ao navegar pelas watchlists e rails, incluindo Kids.

Essas alterações foram commitadas e o APK foi compilado, mas precisam ser testadas na NVIDIA Shield. Não marcar como definitivamente resolvidas até o usuário confirmar o teste.

# MyCinema TV

Protótipo de launcher/catálogo pessoal para Android TV e NVIDIA Shield.

## O que já funciona
- Interface adaptável para TV e navegador.
- Navegação por controle/teclado usando as setas.
- Perfil adulto e área infantil com listas separadas.
- Inclusão manual de filmes e séries.
- Listas persistidas no navegador com localStorage.
- Pesquisa de trailer no YouTube.

## Testar
Abra `index.html` em um navegador moderno. Não há dependências, instalação, build ou backend.

## Limitações atuais
- Os títulos de exemplo são demonstrativos.
- As listas ficam no armazenamento local do navegador; não sincronizam entre aparelhos.
- Os botões UniTV/Stremio ainda não iniciam reprodução.
- Não há integração com Trakt, TMDB ou serviços de streaming nesta versão.

## Próximas etapas
1. Publicar e testar na NVIDIA Shield.
2. Adicionar fontes reais de metadados e integração opcional com Trakt.
3. Avaliar formas suportadas pelo Android TV para abrir apps instalados.
4. Só depois adicionar sincronização e configurações avançadas.

package com.regimtv.launcher

import android.app.Activity
import android.content.Intent
import android.net.Uri
import android.os.Bundle
import android.provider.Settings
import android.view.View
import android.view.KeyEvent
import android.webkit.JavascriptInterface
import android.webkit.WebChromeClient
import android.webkit.WebView
import android.webkit.WebViewClient
import android.widget.FrameLayout
import android.graphics.Bitmap
import android.graphics.Canvas
import android.graphics.drawable.BitmapDrawable
import android.util.Base64
import java.io.ByteArrayOutputStream
import android.widget.Toast
import org.json.JSONArray
import org.json.JSONObject

class MainActivity : Activity() {
    private lateinit var webView: WebView

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        window.statusBarColor = android.graphics.Color.rgb(9, 13, 24)
        window.navigationBarColor = android.graphics.Color.rgb(9, 13, 24)
        window.decorView.systemUiVisibility = (
            View.SYSTEM_UI_FLAG_FULLSCREEN
                or View.SYSTEM_UI_FLAG_HIDE_NAVIGATION
                or View.SYSTEM_UI_FLAG_IMMERSIVE_STICKY
                or View.SYSTEM_UI_FLAG_LAYOUT_STABLE
                or View.SYSTEM_UI_FLAG_LAYOUT_HIDE_NAVIGATION
                or View.SYSTEM_UI_FLAG_LAYOUT_FULLSCREEN
        )

        webView = WebView(this)
        webView.layoutParams = FrameLayout.LayoutParams(
            FrameLayout.LayoutParams.MATCH_PARENT,
            FrameLayout.LayoutParams.MATCH_PARENT
        )
        webView.setBackgroundColor(android.graphics.Color.rgb(9, 13, 24))
        webView.settings.javaScriptEnabled = true
        webView.settings.domStorageEnabled = true
        webView.settings.loadsImagesAutomatically = true
        webView.settings.mediaPlaybackRequiresUserGesture = false
        webView.isFocusable = true
        webView.isFocusableInTouchMode = true
        webView.webViewClient = WebViewClient()
        webView.webChromeClient = WebChromeClient()
        webView.addJavascriptInterface(LauncherBridge(), "RegimNative")
        setContentView(webView)
        webView.loadUrl("https://regisjunior344-jpg.github.io/mycinema-tv/")
    }


    override fun dispatchKeyEvent(event: android.view.KeyEvent): Boolean {
        if (event.action == android.view.KeyEvent.ACTION_DOWN) {
            val key = when (event.keyCode) {
                android.view.KeyEvent.KEYCODE_DPAD_UP -> "ArrowUp"
                android.view.KeyEvent.KEYCODE_DPAD_DOWN -> "ArrowDown"
                android.view.KeyEvent.KEYCODE_DPAD_LEFT -> "ArrowLeft"
                android.view.KeyEvent.KEYCODE_DPAD_RIGHT -> "ArrowRight"
                KeyEvent.KEYCODE_DPAD_CENTER,
                KeyEvent.KEYCODE_ENTER -> "Enter"
                KeyEvent.KEYCODE_BACK,
                KeyEvent.KEYCODE_ESCAPE -> "Escape"
                else -> null
            }
            if (key != null && ::webView.isInitialized) {
                val deliveredKey = if (key == "Enter" && event.repeatCount > 0) "LongEnter" else key
                webView.evaluateJavascript("window.regimHandleRemoteKey ? window.regimHandleRemoteKey('$deliveredKey') : false", null)
                return true
            }
        }
        return super.dispatchKeyEvent(event)
    }

    inner class LauncherBridge {
        @JavascriptInterface
        fun getInstalledApps(): String {
            val intent = Intent(Intent.ACTION_MAIN).addCategory(Intent.CATEGORY_LAUNCHER)
            val resolved = packageManager.queryIntentActivities(intent, 0)
            val seen = mutableSetOf<String>()
            val apps = JSONArray()
            resolved.map { it.activityInfo }.sortedBy { it.loadLabel(packageManager).toString().lowercase() }.forEach { info ->
                val pkg = info.packageName
                if (pkg != packageName && seen.add(pkg)) {
                    val item = JSONObject()
                    item.put("name", info.loadLabel(packageManager).toString())
                    item.put("packageName", pkg)
                    try {
                        val drawable = info.loadIcon(packageManager)
                        val width = if (drawable.intrinsicWidth > 0) drawable.intrinsicWidth else 96
                        val height = if (drawable.intrinsicHeight > 0) drawable.intrinsicHeight else 96
                        val bitmap = Bitmap.createBitmap(width.coerceAtMost(256), height.coerceAtMost(256), Bitmap.Config.ARGB_8888)
                        val canvas = Canvas(bitmap)
                        drawable.setBounds(0, 0, canvas.width, canvas.height)
                        drawable.draw(canvas)
                        val stream = ByteArrayOutputStream()
                        bitmap.compress(Bitmap.CompressFormat.PNG, 90, stream)
                        item.put("icon", Base64.encodeToString(stream.toByteArray(), Base64.NO_WRAP))
                        bitmap.recycle()
                    } catch (_: Exception) { }
                    apps.put(item)
                }
            }
            return apps.toString()
        }

        @JavascriptInterface
        fun openShieldSettings() {
            runOnUiThread {
                try {
                    startActivity(Intent(Settings.ACTION_SETTINGS))
                } catch (_: Exception) {
                    Toast.makeText(this@MainActivity, "Não foi possível abrir as configurações do Shield", Toast.LENGTH_SHORT).show()
                }
            }
        }

        @JavascriptInterface
        fun openPlayStore() {
            runOnUiThread {
                val intent = packageManager.getLaunchIntentForPackage("com.android.vending")
                if (intent != null) startActivity(intent)
                else Toast.makeText(this@MainActivity, "Google Play Store não encontrada", Toast.LENGTH_SHORT).show()
            }
        }

        @JavascriptInterface
        fun launchApp(packageName: String) {
            runOnUiThread {
                val intent = packageManager.getLaunchIntentForPackage(packageName)
                if (intent != null) startActivity(intent)
                else Toast.makeText(this@MainActivity, "Aplicativo não encontrado", Toast.LENGTH_SHORT).show()
            }
        }

        @JavascriptInterface
        fun openExternal(url: String) {
            runOnUiThread {
                if (url.startsWith("https://")) {
                    startActivity(Intent(Intent.ACTION_VIEW, Uri.parse(url)))
                }
            }
        }
    }

    @Deprecated("Deprecated in Android API")
    override fun onBackPressed() {
        // Keep the TV home surface in place instead of leaving the launcher.
    }
}
